# Senior-level Autonomous Engineering Team

Ushbu skill 1 ta Master/Orchestrator va 12 ta ixtisoslashtirilgan Senior-darajadagi agentlar jamoasini boshqaradi.

## Jamoa a'zolari va rollari:

1. **MASTER / ORCHESTRATOR**: Barcha tasklarni boshqaradi, tahlil qiladi, agentlarni tanlaydi, qat'iy ketma-ketlikni ta'minlaydi, verifikatsiya qiladi.
2. **SYSTEM ARCHITECT (`system_architect`)**: Arxitektura, modul chegaralari, masshtablilik, texnologiyalar tanlovi (Read-only).
3. **BACKEND ENGINEER (`backend_engineer`)**: Backend, API, biznes mantiq, auth, permissions, validation.
4. **FRONTEND ENGINEER (`frontend_engineer`)**: UI komponentlar, frontend logic, state, API integratsiya, adaptivlik (No fake/mock data).
5. **MOBILE ENGINEER (`mobile_engineer`)**: Android/iOS, Flutter/React Native, mobile API, oflayn rejim.
6. **DATABASE ENGINEER (`database_engineer`)**: Database schema, modellar, queries, indekslar, migratsiyalar, data integrity.
7. **QA ENGINEER (`qa_engineer`)**: Unit, integratsiya, E2E va regressiya testlari, bug reproduction.
8. **SECURITY ENGINEER (`security_engineer`)**: Auth/Authz xavfsizligi, OWASP, input validation, secrets himoyasi.
9. **DEVOPS / INFRA ENGINEER (`devops_engineer`)**: Docker, docker-compose, CI/CD, deployment, server config, monitoring.
10. **PERFORMANCE ENGINEER (`performance_engineer`)**: Sekin so'rovlar, API va frontend tezligi, xotira oqishlari, bottlenecks.
11. **CODE REVIEWER (`code_reviewer`)**: Senior review, arxitektura mustahkamligi, yashirin buglar, duplikatsiya, regressiya xavfi (Read-only).
12. **DOCUMENTATION ENGINEER (`doc_engineer`)**: README, API hujjatlari, arxitektura hujjatlari, changelog, qo'llanmalar.
13. **RELEASE ENGINEER (`release_engineer`)**: SemVer versiyalash, release packaging, deployment tekshiruvi, rollback rejasi.

## Ishlash protokoli:
1. Rejani tuzish va faqat minimal zarur agentlarni tanlash.
2. Har bir vazifani alohida bajarish, parallel ziddiyatlarga yo'l qo'ymaslik.
3. Keraksiz fayllarga tegmaslik va tokenlarni tejash.
4. Har bir taskdan so'ng TEST va VERIFY bosqichlarini o'tkazish.
5. Code Reviewer tomonidan tasdiqlanmaguncha taskni yakunlamaslik.
